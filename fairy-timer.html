        Notes and ratings

          Sets today's work time back to zero, clears today's time per task, and puts the work countdown back to 1h 0m 0s, not started. The grand total goes down by the same amount. Earlier days are not changed.

          Keyboard shortcuts

          Letters use the physical key, so they work in any input language. Fairy says a short line before Analytics, Achievements and this list open.

          Timer

          SpacePlay / pauseWorks anywhere except while you are typing in a box.
          WStart workRestarts the 1-hour countdown.
          BStart a breakA 5-minute countdown.
          VHide / show the interfaceLeaves only the video until you press V again.

          Windows

          AAnalytics
          CAchievementsM turns achievement sounds on / off. Nothing else is affected.

          EscClose what is openAlso leaves a text box or the task list.
          ZAway alarm on / offWhen it rings, hold Space for 3 seconds to stop it.

          Goal and balance

          ODaily goalType the hours, Enter saves, 0 turns it off, Esc cancels.

          Backup

          XSave a backupA fairy-backup file goes to your Downloads folder.
          IRestore from a backupReplaces everything on the page. A safety copy of the current data is saved first.

          Task list

          TType a new taskTab changes the subject tag (PHY, CHEM, MATH, OTH), Shift+Tab goes back, Esc leaves the box.
          EnterAdd the task you typed
          LFold / unfold the list
          NWrite today's noteIt saves by itself. Esc leaves the box.
          ERate todayThen 1 to 5 or ← → set the stars, 0 or Delete clears, Enter or Esc leaves.
          ↓ ↑Move through the tasks↓ from the text box goes to the first task, ↑ from the first task goes back.

          On a highlighted task

          EnterTick / untickSpace still pauses the timer.
          Delete or BackspaceRemove the task
          1 to 4Set its subject tag1 PHY, 2 CHEM, 3 MATH, 4 OTH.
